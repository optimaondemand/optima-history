# Enlightenment

The Enlightenment, from 1637, beginning with Descartes, and ending with the Reign of Terror (1793 to 1794)
in the French Revolution. A cross-cutting narrative folder like `american-west/`, not a chronological-era
folder; see the root README's note on the two kinds. Its dates mark where the story begins and ends, but it
doesn't exclude other period folders that cover the same years, and a lesson can sit here even when another
folder's timeframe also reaches it. Where the overlap creates a real placement question, such as with
`american-revolution-founding/`, a lesson goes by emphasis: a lesson mainly about Enlightenment thought
belongs here, and a lesson mainly about the founding belongs there. As with every folder here, this boundary
is guidance, not a rule.

# First Contact and the Indian Wars

The stories of first contact, trade, treaties, wars, and conquests involving Native Americans. This is a
cross-cutting narrative folder like `american-west/`, scoped by subject rather than by time period; see the
root README's note on the two kinds. The wars with the Iroquois, Shawnee, Creek, Cherokee, and similar
peoples fall here.

**Placement tiebreaker with `american-west/`:** `american-west/` takes precedence over this folder. The
Sioux, for example, belong here from French contact until the Lewis and Clark expedition; from that point
on, their story belongs in `american-west/`. Where a people's story falls within the American West, it
goes there; this folder holds the rest. As with every folder here, this boundary is guidance, not a rule.

# America in the Long 1990s

American history from the collapse of the Soviet Union in December 1991 to the attacks of September 11,
2001. The "long" 1990s start at the end of the Cold War, not at the calendar decade, and close with the
event that ended the era's sense of itself. Picks up directly where `america-cold-war-era/` leaves off.

A chronological-era folder, not a cross-cutting narrative; see the root README's note on the two kinds. It
is a catch-all for American history within these bounds, in the same spirit as `america-cold-war-era/`. As
with every folder here, this boundary is guidance, not a rule.

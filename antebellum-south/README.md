# Antebellum South

The American South before the Civil War. The end is a hard boundary: the folder stops where the Civil War
begins. The beginning is fuzzier; it starts with the American Republic. Boundaries with other folders
(`american-early-republic/`, `jacksonian-westward-expansion/`, `american-civil-war/`, and others) can be
fuzzy too, and a lesson goes by its emphasis. As with every folder here, this boundary is guidance, not a
rule.

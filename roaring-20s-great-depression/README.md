# Roaring Twenties and Great Depression

Picks up where `gilded-progressive/` leaves off (American entry into World War I): the postwar Twenties
(consumerism, the Jazz Age, Prohibition, immigration restriction), the 1929 crash, and the Great
Depression, running through American entry into World War II, which is this folder's bookend.

A lesson whose point is explaining how the Depression (or the era generally) fed into WWII belongs in
`world-war-ii/` instead, regardless of date — see that folder's README. This folder is for the American
domestic story on its own terms.

Currently empty — no lesson content ported yet.

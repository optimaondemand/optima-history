# Ancient Anatolia

The Anatolian peninsula (modern Turkey) from earliest farming through Cyrus's conquest of Lydia, which is this
folder's bookend (around 546 BC); the Persian-side story continues in `persian-near-east/`. Covers early
farming in Anatolia, the Hittite Empire and its rivalry with Egypt, and the kingdoms that followed it, including
Lydia. As with every folder here, this boundary is guidance, not a rule.

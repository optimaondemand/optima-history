# Pre-Columbian America

What we know about the Indians of the Americas before European contact. Strictly speaking this is not
history in the ordinary sense, since the peoples involved left no written records; what we know comes from
other kinds of evidence. Contact with Europeans is the boundary: the story picks up in `age-of-exploration/`
once Europeans arrive. As with every folder here, this boundary is guidance, not a rule.

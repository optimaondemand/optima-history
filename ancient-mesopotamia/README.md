# Ancient Mesopotamia

The land between the Tigris and Euphrates from the first farming villages through the Persian conquest, which
is this folder's bookend: Babylon falls to Cyrus in 539 BC, and the Persian-side story continues in
`persian-near-east/`. Covers Sumer and the first cities and writing, Akkad, Babylon under Hammurabi, the Assyrian
Empire, and the Neo-Babylonian Empire. As with every folder here, this boundary is guidance, not a rule.
